# 热点、扫描与 Wi‑Fi 探测体系

## 1. 功能定位

热点相关功能主要体现在 src/wifiseclab/hotspot.py 与 hotspot_cli.py。其重点不是直接建立网络，而是：

- 构造扫描请求
- 判断广告/RSN 参数
- 处理认证与关联所需的上下文
- 关注 AP 端口策略与受控环境下的安全语义

## 2. 关键能力

- discover：发现候选热点
- probe：针对特定 SSID / BSSID 进行观察
- auth：模拟认证前置事件
- associate：构造和分析关联语境
- build：构造原始 802.11 数据和 RSNE 上下文

## 3. 设计边界

该层的目标并不是“验证完整无线管理堆栈”，而是限定在可控实验和审计场景中进行：

- 识别目标热点
- 排除错误的 AP 身份
- 绑定特定 BSSID / SSID / station
- 不对外部无线环境做绝对安全结论

## 4. 对项目的作用

当状态机需要描述“认证前”、“关联前”、“前提条件满足”等阶段时，热点入口负责为这些阶段提供真实可检查的上下文数据。
