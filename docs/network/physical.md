# 物理网卡与发送/监听分工

## 1. 定位

物理层功能主要对应 src/wifiseclab/physical.py、radio_roles.py、radio_handshake.py 等模块，它们重点处理：

- 物理网卡识别
- 发射角色与监听角色分工
- handshake 过程中的时间/时序边界
- 实验环境下的单帧真实性和约束

## 2. 关键原则

该部分强调：

- 发送和监听不能完全等同于整个链路已验证
- 实验环境中的物理角色分工只能保证有限范围内的证据
- 单帧、单网卡或单角色实验不能轻易推出全链路安全结论

## 3. 价值

它为项目提供了真实设备层面的实验路径，但同时也保留了边界：

- 仅是受控无线实验
- 不是完整协议栈认证
- 结论仅能支撑特定实验范围

## 4. 与状态机关系

物理层提供“事件来源与实验上下文”，而状态机负责决定这些事实是否满足安全语义。
