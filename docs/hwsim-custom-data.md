# 自定义握手后的加密数据往返

新增 lab_datagram.py：构造固定隔离实验地址的正常 IPv4/UDP 请求、计算 IP/UDP checksum，以及单一新 TK 上的 CCMP-128 uplink PN 分配器。PN 在加密前递增，失败不回滚；没有 caller-selected PN 或自动重传。调用者必须对新 TK 只创建一个分配器，不能为同一 TK 重新实例化。这个实验 API 不提供跨进程持久 PN 状态。

hwsim 自定义 harness 为 AP 配置 192.0.2.1/30，静态绑定虚拟 STA 的 192.0.2.2 邻居项（避免本实验需要实现 ARP），启动自有 UDP 回显服务。客户端沿用自定义认证/关联/M2/M4，验证该轮 RSNE/MIC 握手后派生 TK，发送一帧正常加密请求，再独立监听解密响应。仅允许 mac80211_hwsim 接口；不通过 wpa_supplicant 代替自定义 STA。

实际结果：client 与 harness exit 0；AP 授权快照为真；服务端确认收到该轮随机标记；独立离线分析抓包中的请求包 71 和响应包 73，两者 CCMP MIC、UDP checksum、地址端口及随机负载均匹配。上下行 PN 各为 1，发送方 A2 不同，因此 nonce 不同。结果见 hwsim-custom-verification/data-analysis.json。

发送前原始帧摘要和抓包帧摘要可能不同，驱动可修改不参与 CCMP AAD 的时长/序列号。独立检查依据密码学验证与严格负载解析，没有把字节摘要不相等误作发包失败。

222 项测试通过，包括重复负载分配不同 PN、加密失败消耗 PN、PN 耗尽拒绝、地址及 UDP 校验和。实验后确认模块/命名空间已清理，实体接口为 managed。本轮未使用实体网卡发包。

这完成了自定义正常 PSK 会话的一条隔离数据往返路径，没有将 TK 安装到 STA 内核，不是通用 IP 客户端。尚需抽取可复用数据面会话状态机、实现重键/边界及保护策略、加固实验快照的读取和证据归档、验证生产物理适配器，以及继续标准和近 30 年论文精读。总目标仍未完成。
