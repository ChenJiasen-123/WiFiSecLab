# hwsim 实验与受控验证环境

## 1. 定义

hwsim 实验是本项目中最关键的受控验证路径之一。相关脚本位于 tools/ 下，并配合 src/wifiseclab/ 中的状态机与分析模块使用。

## 2. 目的

该环境的目标是：

- 在隔离的 Linux hwsim 环境中构造握手
- 验证正常/异常状态转换
- 观察 AP/STA 端参数与 key lifecycle
- 复现关键状态变化；不把观察结果直接视为一切都正常

## 3. 关键实验类型

- 自定义握手
- 加密数据往返
- 生命周期复现
- key install / delete / cleanup 校验
- 断开和重连状态采样

## 4. 关键边界

hwsim 是非常有价值的实验环境，但它不是完整的真实市场网络环境：

- 只验证受控实验路径
- 不等价于所有设备、固件和生产环境
- 不可直接推定真实 AP/客户端链路全部安全

## 5. 与项目主线关系

实验层提供事实轨迹，状态机层提供状态判定，生命周期层提供结论边界。三者一起构成项目的核心研究闭环。
