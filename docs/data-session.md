# 有界数据阶段状态机

新增 data_session.py 并接入 hwsim_custom_client。DataSession 在明确的新 TK 上只分配一个请求，使用有限单调时限、最多 4096 个输入观察。验证响应的 CCMP MIC、IPv4/UDP、地址端口和随机标记；本地接收 PN 按优先级递增，旧 PN 不产生第二次成功。超时、时钟倒退、请求构造错误和上下文关闭后不能继续旧事务。

属于本轮 AP/STA 的断开（包括 AP 广播）、新认证/关联、明文或完整性通过的加密 EAPOL 会关闭上下文。无法解释的本轮受保护管理帧也保守关闭。观察断开不等于 AP 确认断开；未知重键语义不继续沿用旧 TK。其他站点的断开不影响本轮。

握手到数据的交接也检查最终 M4 后是否已出现边界/新 M1/M3；transport 切换为数据开始时刻的捕获 cutoff，避免将旧握手报文误认成本轮数据阶段新事件。

227 项测试通过：实际加密响应完成一次、单播/广播断开后的旧响应被拒绝、明文重键/受保护管理边界、其他站点隔离、错误 MIC、超时和时钟倒退。边界报文仅在内存测试中构造，没有在真实无线环境发送。

最终版本 hwsim 实跑仍成功：自定义认证、关联、M2/M4 与加密 UDP 往返均通过，独立抓包包 69/71 的 MIC、IP/UDP checksum、身份和负载匹配；AP 授权快照为真。实验结束后 hwsim 和命名空间已清理，实体接口为 managed。本轮未使用实体网卡。

范围：仅支持初始 PSK/CCMP、固定隔离 UDP 端点和单次事务。不自动处理重键、PMF/SAE/FT、不证明 AP 内部状态或接收端重放策略。仍需继续标准/漏洞论文精读、生产适配器及更广上下文/边界验证。
