# 研究资料与背景索引

## 1. 作用

docs/research/ 中的材料用于保存：

- Wi‑Fi 安全研究背景
- 参考文献抽取
- 状态边界与协议细节解读
- 关键研究结论与反驳材料

## 2. 主要内容

这个目录覆盖的主题包括：

- handshake context
- SAE / RSN / PMF / replay 边界
- lifecycle snapshot binding
- control snapshot 与 key evidence
- 认证与关联的边界行为
- hwsim 数据验证与持久状态分析

## 3. 使用方式

建议在写论文或设计实验时，先阅读：

- docs/architecture/overview.md
- docs/protocol/eapol.md
- docs/lifecycle/overview.md

然后再查看 docs/research/ 中具体笔记，以对应到标准文献、边界条件和异常情况。
