# 身份约束与 NDSS 2005 主体阅读（2026-10-10）

本轮完成论文主体各章节的文本阅读（第 1–6 节，结合前几轮已读内容）；参考文献、附录仍未完整核查，图形与抽取异常的指数公式未逐项视觉验证，因此不将全篇技术精读标为完成。

来源：He 与 Mitchell，Security Analysis and Improvements for IEEE 802.11i，https://www-cs.stanford.edu/people/jcm/papers/NDSS05.pdf 。本轮重点补读第 2 后半、3、4.1 前半、4.3–4.4、5.1–5.3。核心成因索引：兼容旧协议时的安全策略降级；同一密钥下角色混用；未认证上下文干扰；错误恢复放大资源消耗。论文依赖其历史威胁模型；其安全断言和改进方案不能直接作为现代实现结论或规范要求。特别是 CCMP 分析中的新鲜密钥、PN 不重复假设应独立验证，不能由 MIC 成功替代。历史 RSNE 放宽、TKIP 计数更新和阶段重排建议未移植到平台。

代码核查与修改：构帧入口 mac_bytes 已拒绝组播和零地址，derive_kck 原先只检查长度及 AP/STA 不相同，导致公共密钥派生 API 接受不属于基线单播会话的输入。现统一要求两个不同、非零、单播的六字节 bytes 地址。derive_kek 与 derive_tk 复用此校验。拒绝组播、广播、零地址、错误长度、字符串、可变字节数组以及其他错误类型，保留本地管理单播地址支持。

这项校验约束基线测试会话输入，不认证地址拥有者，不代表解决跨设备或跨角色反射攻击，也没有加入相关攻击包构造或发送功能。构帧、捕获及会话方向匹配仍由已有模块分别验证。

验证：240 项离线测试通过；新增三个密钥切片入口的非法身份矩阵与本地管理地址回归，既有独立 hwsim 捕获对应 M2/M4 字节级验证仍通过。本轮没有远程连接、无线发包或新的 hwsim 实验。
